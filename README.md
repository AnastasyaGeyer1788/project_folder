# 🎯 Vacancy Parser - Парсер вакансий с hh.ru

Программа для поиска, фильтрации и анализа вакансий с платформы hh.ru. Сохраняет данные в JSON файл и предоставляет удобный интерфейс для работы с вакансиями.

## ✨ Возможности

- 🔍 **Поиск вакансий** на hh.ru по ключевым словам
- 💾 **Сохранение данных** в JSON формате
- 🎯 **Фильтрация** по зарплате, ключевым словам, опыту и городу
- 📊 **Топ-N вакансий** по зарплате
- 🧹 **Удаление дубликатов** и очистка базы
- 🧪 **Полное тестовое покрытие** (>95%)

## 📦 Установка

1. **Клонируйте репозиторий:**
```bash

git clone https://github.com/AnastasyaGeyer1788/project_folder.git
cd project_folder
```
2. **Создайте виртуальное окружение:**
```bash

python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
```
3. **Установите зависимости:**
```bash

pip install -r requirements.txt
```

## 🚀 Использование
Запуск программы:

## 🏗️ Архитектура проекта

```text
project_folder/
├── data/                 # Директория с данными
│   └── vacancies.json    # Файл с вакансиями

│   ├── api/              # Модуль для работы с API
│   │   └── hh_api.py     # API HeadHunter
│   ├── file_workers/     # Работа с файлами
│   │   └── json_saver.py # Сохранение в JSON
│   ├── models/           # Модели данных
│   │   └── vacancy.py    # Класс вакансии
│   ├── utils/            # Вспомогательные функции
```
